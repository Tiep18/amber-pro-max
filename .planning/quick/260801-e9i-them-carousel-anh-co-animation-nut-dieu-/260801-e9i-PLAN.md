# Add an animated, swipeable product image carousel

## Goal

Upgrade the product-detail gallery so customers can browse multiple images with clear previous/next controls, mobile swipe gestures, thumbnail selection, and restrained motion while preserving the existing image, SEO, and storefront boundaries.

## Tasks

1. Add small, unit-tested gallery index/swipe helpers with bounded navigation and a deliberate swipe threshold.
2. Refactor `ProductGallery` into a translated, accessible carousel track with animated transforms, drag feedback, arrow-key and button navigation, thumbnail selection, and reduced-motion support.
3. Pass localized gallery labels from the product route and verify unit tests, type safety, lint, and production build behavior.

## Done when

- Multiple images can be selected using previous/next buttons, thumbnails, keyboard arrows, or horizontal mobile swipes.
- Image changes animate with transform-based motion and collapse to no motion under `prefers-reduced-motion`.
- Controls have localized accessible names, visible focus, disabled edge states, and at least 44px touch targets.
- Single-image and empty-image galleries retain their current simple presentation without unnecessary controls.
