# Quick Plan

## Goal

Update the guest cart immediately after checkout creates an order successfully, while preserving unrelated items and any quantity that was not actually included in the order.

## Tasks

1. Add a pure cart reconciliation helper and expose an order-completion operation from `CartProvider`.
2. Invoke that operation only after a successful checkout response, using the final quoted quantities, and cover the behavior with automated tests.

## Must Haves

- A stale quote, validation error, payment error, or failed order creation never changes the cart.
- Successful order creation subtracts only the quantity persisted in the order.
- Unrelated lines, quote-capped surplus, and concurrent quantity increases remain in the cart.
- The persisted guest cart and quote cache are updated before navigation.
- Unit and checkout boundary tests protect the contract.

## Verification

- Run focused cart and checkout tests.
- Run lint, typecheck, the full automated test suite, and production build.
- Exercise the successful checkout path against the running app and remote Supabase if browser state permits a non-destructive test setup.
