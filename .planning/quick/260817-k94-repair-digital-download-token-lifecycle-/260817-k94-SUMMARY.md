## Decisions Made

- Kept raw capability material ephemeral in the email worker; no raw value enters RPC arguments, durable payloads, audit facts, or logs.
- Kept generic transactional email retry on the same outbox row unchanged; only digital manual resend creates a new entitlement-versioned intent.
- Used the cookie-backed authenticated Supabase client for admin reissue so `private.is_admin()` and `auth.uid()` see the real JWT.
- Kept customer error behavior deliberately non-enumerating: every denial and internal authorization/signing failure maps to the same `404 {status:'not_found'}`.
- Added no queue infrastructure or paid service; the implementation remains compatible with Vercel Free request execution and Supabase Free Postgres/Storage.
