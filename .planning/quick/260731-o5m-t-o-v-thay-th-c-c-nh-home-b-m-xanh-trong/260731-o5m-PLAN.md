# Replace cool-toned home imagery

## Goal

Replace the four home-page raster assets with warmer, brand-aligned versions while preserving their subjects, compositions, dimensions, filenames, and existing page references.

## Tasks

1. Edit each existing home image with the built-in image generator, removing cool blue/sage casts and applying the project's cream, warm brown, terracotta, blush, and honey palette.
2. Inspect each result, copy the selected outputs over the existing files in `public/images/home`, and normalize them to their original pixel dimensions.
3. Verify image decoding, aspect ratios, file references, build/type safety, and the final visual set.

## Done when

- `hero-studio.png`, `handmade-category.png`, `pattern-category.png`, and `maker-story.png` all feel visually consistent with the storefront palette.
- No layout or source-code reference changes are required.
- All four assets decode correctly at their original dimensions.
