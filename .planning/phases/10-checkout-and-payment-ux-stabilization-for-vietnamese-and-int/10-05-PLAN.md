<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authorized order projection -> browser presentation | Browser can render/recheck/restore intent but cannot create paid/payment/inventory truth. |
| Terminal order snapshot -> fresh cart | Recovery is local intent only and must be requoted into a new order. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T10-08 | Tampering / Repudiation | terminal payment recovery | mitigate (ASVS V4/V5) | Keep sameOrderRetryAllowed false, remove provider/checkout actions, restore intent to cart, and security-test no terminal retry. |
| T10-09 | Tampering | payment paid/deadline presentation | mitigate (ASVS V4/V5) | Render from authorized server projection only, show deadline only for pending/verifying, and forbid paid mutation/client state machine. |
| T10-SC | Tampering | dependencies | avoid | No package, provider SDK, database state, or payment schema change is allowed. |
</threat_model>
