<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL/cookies/geo -> proxy | Untrusted preferences enter server resolution. |
| Browser action -> HttpOnly cookie | Only strict enum mutations are accepted. |
| Context endpoint -> browser | Minimal personalized data must never be publicly cached. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Spoofing | Cookie/geo | mitigate | Strict enum, cookie precedence, suggestion-only semantics, destination untouched. |
| T-09-02 | Information disclosure | Public/static routes | mitigate | Request resolution stays proxy/private endpoint only. |
| T-09-04 | Spoofing | Return/query | mitigate | Internal localized routes and per-route allowlists. |
| T-09-06 | Tampering | Mutation result | mitigate | Server-confirmed enum; client orchestration deferred to context provider. |
| T-09-07 | Information disclosure | Context API | mitigate | `private, no-store` on every response. |
| T-09-08 | Information disclosure | Errors/logs | mitigate | Stable codes and bounded facts; no raw cookie/header/query logging. |
| T-09-SC | Tampering | Dependencies | accept | No install/upgrade. |
</threat_model>
