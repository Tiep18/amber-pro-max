<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored quote -> current context | Cached data may belong to another market/version. |
| Browser cart intent -> server quote | Prices/availability are not accepted from client. |
| Browsing market -> destination checkout | Destination must remain final physical quote authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Spoofing | Browsing vs destination | mitigate | Server quote derives market; destination lifecycle unchanged. |
| T-09-03 | Tampering | Cache/requote races | mitigate | Context identity, request IDs, stale no-op, fail-closed UI. |
| T-09-05 | Elevation of privilege | Cart/submit | mitigate | Intent-only calls; fingerprint/version excluded from authority. |
| T-09-06 | Tampering | Cross-tab context -> cart | mitigate | Authoritative refetch then server requote. |
| T-09-07 | Information disclosure | Quote cache | mitigate | sessionStorage only, strict identity/TTL, no private projection bodies. |
| T-09-08 | Information disclosure | Errors/summary | mitigate | Localized bounded facts; no hashes/addresses/raw payloads. |
| T-09-SC | Tampering | Dependencies | accept | No install. |
</threat_model>
