| Boundary | Description |
|----------|-------------|
| Public ISR/cache -> all visitors | Shared output must never vary by cookie/IP market. |
| Private projection request -> database cache | Inputs are untrusted and market is server-derived. |
| Projection fingerprint -> cart/checkout | Fingerprint is presentation evidence only. |
