## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User control -> server cookie | UI intent cannot become committed until server success. |
| Current URL/query -> locale navigation | External or unrelated state must not propagate. |
| Cross-tab/focus -> controls | Labels cannot trust broadcast payloads. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-03 | Tampering | Rapid control input | mitigate | Provider generation/latest intent and fail-closed purchase. |
| T-09-04 | Spoofing | Locale/query navigation | mitigate | Equivalent internal paths and explicit allowlists. |
