## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Private context response -> client state | Responses may be stale, failed, or delayed. |
| Other tab/focus -> provider | Events cannot carry authoritative commerce facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Spoofing | Context response | mitigate | Consume server-resolved enum only; locale/IP not client authority. |
| T-09-03 | Tampering | Async lifecycle | mitigate | Abort, generation guards, fail-closed status, rollback. |
| T-09-05 | Elevation of privilege | Context version | mitigate | Version gates UI only and is absent from quote/submit authority. |
| T-09-06 | Tampering | Cross-tab/focus | mitigate | Invalidation-only payload and server refetch. |
| T-09-07 | Information disclosure | Context fetch | mitigate | no-store request and server private response. |
| T-09-08 | Information disclosure | Client errors | mitigate | Stable bounded codes; no response/cookie/header logging. |
| T-09-SC | Tampering | Dependencies | accept | Native browser primitives; no install. |
</threat_model>
